GlowWell هو نظام متطور لمتابعة الصحة واللياقة البدنية، مصمم ليمنح المستخدم تجربة ذكية في تسجيل الوجبات، حساب الماكروز (البروتين، الدهون، الكربوهيدرات)، ومتابعة شرب الماء، مع نظام إشعارات ذكي لضمان الالتزام.

🚀 المميزات الرئيسية
نظام ذكي لحساب السعرات: بناءً على وزن المستخدم وهدفه (خسارة أو بناء).

تتبع الماكروز: رسوم بيانية دقيقة توضح التقدم اليومي لكل عنصر غذائي.

إدارة الجلسات السحابية: تخزين جلسات المستخدم في قاعدة البيانات لضمان عدم فقدان التسجيل.

نظام إشعارات (Push Notifications): إشعارات ذكية باستخدام Firebase Cloud Messaging (FCM).

واجهة عصرية: تصميم باستخدام Tailwind CSS يوفر تجربة مستخدم سلسة ومتجاوبة.

🛠 المتطلبات التقنية
PHP: إصدار 7.4 أو أحدث.

MySQL: لإدارة قاعدة البيانات.

Composer: لإدارة مكتبات الـ JWT (لازمة للإشعارات).

Web Server: خادم يدعم Apache (مثل XAMPP).

⚙️ كيفية الإعداد (Installation)
قاعدة البيانات:

قومي بإنشاء قاعدة بيانات جديدة باسم glowwell_db.

قومي باستيراد الجداول اللازمة (users, user_meals, water_logs, sessions, user_devices).

هام: تأكدي من إضافة UNIQUE KEY لجدول الـ water_logs للعمودين (user_id, log_date).

الإعدادات:

افتحي ملف config.php وقومي بتعديل بيانات الاتصال بالسيرفر (localhost, root, password).

تأكدي من وضع ملف الـ JSON الخاص بـ Firebase في المجلد الرئيسي وتسميته glowwell-ac819-337663ab54b3.json.

التشغيل:

ضعي المشروع داخل مجلد htdocs الخاص بـ XAMPP.

افتحي المتصفح وانتقلي إلى http://localhost/glowwell/login.php.

🔒 ملاحظات الأمان
تشفير كلمات المرور: يتم تشفير كلمات المرور باستخدام password_hash() قبل التخزين.

الحماية من الثغرات: تم استخدام Prepared Statements في جميع عمليات قاعدة البيانات لمنع حقن SQL.

النسخ الاحتياطي: يوصى بأخذ نسخة احتياطية دورية لقاعدة البيانات (mysqldump) لضمان سلامة بيانات المستخدمين.

🛡 الخصوصية والقانون
يلتزم GlowWell بحماية بيانات المستخدمين وعدم مشاركتها مع أطراف ثالثة.
